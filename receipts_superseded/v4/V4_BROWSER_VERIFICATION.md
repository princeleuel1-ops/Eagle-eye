# V4 BROWSER VERIFICATION

**Status: EXECUTED — real headless Chromium against the real local server.**
This closes wall W3, open since V1 ("the sandboxed remote browser cannot
reach this container's localhost server" no longer applies: Chromium runs
IN-environment via Playwright).

## How it runs
- `make browser` (also inside `make check` as the `browser` gate; the
  completeness guard refuses overall PASS if it is skipped)
- `scripts/browser_verification.py`:
  1. starts `eagle_eye.server` on a FRESH unused localhost port
     (`EAGLE_EYE_PORT`)
  2. launches headless Chromium (Playwright), capturing ALL console errors,
     page errors, request failures, and HTTP ≥400 responses
  3. drives the full audit-required workflow
  4. writes `artifacts/browser/latest/BROWSER_VERIFICATION.json` + a
     full-page screenshot `cockpit.png`

## Honest limits
- One engine (Chromium headless fallback build for this OS). No Firefox/
  WebKit matrix, no visual-regression baseline. The gate proves functional
  correctness and zero-error rendering, not pixel fidelity.
- On a workstation: `make setup` installs the pinned Playwright and the
  Chromium shell; `make run` + a manual visit remains available for human
  review.
